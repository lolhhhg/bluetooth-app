"""
Quick Start Guide for Bluetooth Manager
========================================

RUNNING THE APP
---------------

1. Window Mode (Full GUI):
   python bluetooth_manager.py

2. System Tray Mode:
   python bluetooth_manager.py --tray


BUILDING EXE (Windows only)
---------------------------

Option 1 - Quick Build:
   Double-click build_exe.bat

Option 2 - Manual:
   pip install -r requirements.txt
   pyinstaller --onefile --windowed --name "BluetoothManager" bluetooth_manager.py

The executable will be in the dist/ folder.


FEATURES
--------
✓ Scan for Bluetooth devices
✓ Connect/Disconnect devices
✓ Check battery levels
✓ Auto-refresh every 30 seconds
✓ Modern dark interface
✓ System tray icon


TROUBLESHOOTING
---------------

"No modules found":
   pip install bleak pystray Pillow

"Permission denied":
   Run as Administrator

"No Bluetooth adapter":
   Make sure Bluetooth is enabled on your computer


DEMO MODE
---------
If bleak is not installed, the app runs with simulated devices
for testing the interface without actual Bluetooth hardware.
